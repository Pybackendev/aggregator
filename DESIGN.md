# FH Aggregator

The feed is a daily shortlist. A card leads with the project title, amount and status, then offers the original Freelancehunt page, the description and a favorite toggle.

Keep dark as the initial theme. Light keeps the same hierarchy with cool neutral surfaces and a blue accent. The CSS custom properties in frontend/src/index.css own both palettes. Preserve Inter and the existing navigation. Make keyboard focus visible, let filters wrap on mobile, and keep long titles and descriptions within the card.

Use source currencies and dates, clearly distinguish an unknown budget or status, and show the last successful import separately from loading the feed.
